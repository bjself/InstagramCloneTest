## ℹ️ About This Pirate's Booty

![alt text](images/mockup.png "Title")

Shiver me timbers! This repo contains the treasure from me youtube channel called simcoder. This project be a plundered copy o' the Instagram android app, worthy of any scallywag!

It be built usin' React Native with Expo, wieldin' firebase services (authentication, firestore and storage) like a cutlass.
The admin panel be crafted with ReactJS, fit fer a captain.
The backend be all NodeJS, smooth as the seven seas.

In the [master](https://github.com/SimCoderYoutube/InstagramClone/tree/master) branch ye have the redesign treasure, which I was previously sellin' on me website, however ye still be havin' access to the youtube series repo in the [youtube_series](https://github.com/SimCoderYoutube/InstagramClone/tree/youtube_series)

Ye can follow the youtube series voyage in the followin' [link](https://www.youtube.com/watch?v=xE8UEX7vXVQ&list=PLxabZQCAe5fgatwOQny9wKJVs4YD6xkf1)
